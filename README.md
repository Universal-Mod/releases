# UMOD

Mods and missions for Arma 3.

- [Downloads](https://umod.rocks/downloads)
- [Release history](https://github.com/Universal-Mod/releases/releases)
- [Website](https://umod.rocks)
- [Discord](https://discord.gg/TM89VN7Y7P)

For missions, download the ZIP attached to the release. For mods, use the Steam Workshop link in the release notes. Each release lists its requirements and installation steps.

GitHub's **Source code** downloads do not contain the mission or mod.
